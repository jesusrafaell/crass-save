# CrashSaver Parking Go

[![Go Reference](https://pkg.go.dev/badge/golang.org/x/example.svg)](https://pkg.go.dev/golang.org/x/example)

## Clone the project

```
$ git clone
$ cd api-parking
```

## Requirements

- Version: >= go1.22.0

```
$ go mod download
```

## Run Project

```
$ go run cmd/api/main.go
```

## Using Make

```
$ make dev
```

## Build using Make

```
$ make build
```
